# Новый проект в хабе

Создай обвязку проекта `$ARGUMENTS` (если имя не передано — спроси).

Шаги:
1. Скопируй `templates/project/` в `projects/$ARGUMENTS/` (относительно корня хаба — папки, где лежит этот
   `.claude/`; сейчас `W:\ai-dev-hub`). Папки `projects/` нет — создай.
2. Открой созданный `projects/$ARGUMENTS/CLAUDE.md` и заполни его вместе с пользователем: коротко проинтервьюируй — что за проект, стек, где рабочий репозиторий (GitLab/GitHub URL), команды сборки/тестов/линта, что нельзя трогать.
3. Если пользователь дал URL репозитория — склонируй его в `projects/$ARGUMENTS/repo/` (спроси подтверждение перед клонированием).
4. Напомни: рабочие сессии по проекту запускать из `projects/$ARGUMENTS/repo/` — тогда автоматически подхватятся и правила хаба, и CLAUDE.md проекта.
5. НЕ коммить: `projects/` целиком в `.gitignore` хаба, обвязка и память проекта живут только на этой машине.
