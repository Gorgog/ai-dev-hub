Читает скилл `dispatch` (`<хаб>/plugin/skills/dispatch/`). Здесь — только специфика проекта. Профиль лежит в
локальной папке проекта и в git хаба не входит.

- **Запрещено сессиям задач:** <скиллы, которые сами пушат, создают MR или переключают ветки основной копии>.

## Пути
- repo: `<хаб>/projects/<имя>/repo`
- worktrees: `<хаб>/projects/<имя>/worktrees/<ветка>` (внутри проекта: CLAUDE.md хаба и проекта
  подгружаются сами). Имена веток короткие — `<KEY>-NN`.
- Создание: `bash <хаб>/plugin/skills/dispatch/scripts/wt-new.sh <repo> <worktrees> <ветка> <база> <env-файлы…>`
- Замер: `bash <хаб>/plugin/skills/dispatch/scripts/headroom.sh -Ports <порты> -Worktrees <хаб>/projects/<имя>/worktrees`
- Прогоны: `bash <хаб>/plugin/skills/dispatch/scripts/hub-run.sh --list`, погасить —
  `… hub-run.sh --stop <worktree>`
- Проверка конфликтов: `bash <хаб>/plugin/skills/dispatch/scripts/parallel-check.sh <repo> <родитель волны> <ветки…>`
- Уборка: `bash <хаб>/plugin/skills/dispatch/scripts/wt-remove.sh <repo> <worktree>`
- Доска: `memory/dispatch.md`

## Лимиты
- Сессий задач — до <N> (по умолчанию 7: до 5 свободно, 6–7 — с `headroom.sh -MinPhysGB 5`). Тяжёлое — одно на всех. Выдавать при коде 0 `headroom.sh` (запас: доступная память +
  свободный swap/zram ≥ <N> ГБ, PSI памяти ниже порогов); свой `-MinGB`/`-MinPhysGB` — если по умолчанию мало.
