# Защита механизмом (срез 13)

Частые и опасные ошибки останавливает хук, а не текст правила. Четыре механизма под одним логическим обработчиком
`protect` (бюджет: 5 обработчиков из 6): модули `plugin/hooks/pretool.d/30..33-*.cjs`, логика — `plugin/hooks/protect.cjs`,
записи — `plugin/mechanisms/<id>.json`, тесты — `plugin/hooks/protect.test.cjs`, полигон — H17–H21. Решение — `deny` с
причиной, которая говорит, что делать вместо; сломанный модуль закрыт внутри проектов хаба (`onError: closed`,
`failScope: project`). Bash читается разбором shell (кавычки, `$( )`, heredoc, перенаправления, `cd` и `S=…; $S` в
пределах команды), не подстрокой: текст в сообщении коммита, в `echo` и в теле heredoc не срабатывает.

| Механизм | Запрещает | Пропускает |
|---|---|---|
| `protect-files` | правку существующего `.env`/`.env.*`, локфайла (`package-lock.json`, `pnpm-lock.yaml`, `yarn.lock`, …), миграции, уже лежащей в HEAD (папка `migration(s)/`) — Edit/Write/MultiEdit/NotebookEdit и запись из Bash (`>`, `>>`, `tee`, `sed -i`, `cp`/`mv`/`rm`, `git rm`) | чтение; `.env.example` и прочие образцы; новый `.env`; новую миграцию (нет в HEAD); `git add` локфайла |
| `inline-script` | скрипт `node -e "…"`, `python -c "…"`, `perl -e "…"` или heredoc без кавычек в интерпретатор/в файл кода, где shell сам перепишет тело: обратная кавычка, `\\`, `${…}`, который не параметр shell. В причине — путь для Write и готовая команда | `'…'` и `<<'EOF'` — тело доходит как набрано; `$VAR` и `${VAR}` в двойных кавычках (подстановка пути намеренная) |
| `agent-model` | `Agent`/`Task` с `subagent_type` `reviewer` (`hub:reviewer`) и `model` не Opus | без `model` (её задаёт `reviewer.md`) и `opus`; другие агенты |
| `agent-roles` | всем — запись в `.claude/agent-memory/`; ролям `tester`/`reviewer`/`explorer` — запись в память проекта хаба (`projects/*/memory/`) и меняющий git в рабочем репозитории; `reviewer`, `explorer` — любую запись в рабочий репозиторий; `tester` — запись не в тест (`*.test.*`, `*.spec.*`, `test_*.py`, `tests/`, `__tests__/`, `fixtures/`, …) | своё: scratchpad, `/tmp`, временный репозиторий там; чтение и узкий прогон тестов; основную сессию и `general-purpose` |

Рабочий репозиторий для `agent-roles` — `git rev-parse --show-toplevel` от `cwd` вызова, иначе сам `cwd`. Путь с
неизвестной переменной не судится (пропуск, а не ложный блок).

## Выкат и откат

Записи на стадии `canary`: модуль работает только в проектах, чей `projects/<имя>/canary.json` перечисляет его. Порядок
(R2): проект хаба → проект B → `stage: "on"`, по рабочему дню на ступень, глядя в журнал хуков (`type=error`) и в
отказы. `hooks.json`: матчер PreToolUse теперь видит `Agent`, `Task`, `NotebookEdit` — живые сессии берут новый
матчер только при старте. Откат — `stage: "off"` в записи (сразу), либо revert; аварийно — `<хаб>/.hub-off`.
