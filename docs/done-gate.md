# «Готово» по фактам (срез 16)

Доклад «готово к пушу» и «зелёные тесты» проверяет хук, а не память сессии. Пять модулей под одним логическим
обработчиком `done-gate` (бюджет — `docs/hooks.md`); логика — `plugin/lib/done-gate.cjs` и `plugin/lib/note-stub.cjs`,
записи — `plugin/mechanisms/<id>.json`, полигон — H01, H09, H28–H30.

| Модуль | Стадия | Что делает |
|---|---|---|
| `stop.d/10-done-gate.cjs` (`done-gate`) | on | Доклад — строка, которая **начинается** с «готово к пушу» / «готово к мержу» (`**…**`, `- …`, `## …` — тоже; цитата `> …` — пересказ, не доклад). Упоминание в плане, статусе, оценке, пересказ диспетчера — не доклад (H01: 35 из 35 блоков v1 были на них). Копия — `worktrees/<имя>` из текста доклада, иначе `repo/` или worktree папки сессии; папка проекта — не судится. Блок: грязное дерево, в тексте нет sha HEAD (7+ hex — префикс полного sha). |
| `stop.d/11-done-facts.cjs` (`done-facts`) | canary | В проекте с `checks.json`: `checks.cjs --full` прогнан **на итоговом HEAD** чистого дерева и зелёный (`last-full.json`). Любой коммит после прогона — доки, план — нужен новый прогон: срез 11 нашёл 35 из 59 докладов без него, чаще всего так. Доклад о пуше: ветка не отстала от базы (`base` из `checks.json`, иначе ветка основной копии; база не читается — не блок). |
| `posttool.d/10-test-output.cjs` (`test-output`) | canary | Bash вышел с кодом 0 (PostToolUse приходит только тогда), а в сводке тестов упавшие или пропущенные — блок со строкой сводки. vitest (`Test Files`/`Tests … N failed\|skipped\|todo … (M)`), jest (`Tests:`/`Test Suites: … N failed\|skipped, … total`), `node --test` (`# fail N`, `ℹ skipped N`, `cancelled`, `todo`). Считается только начало строки: тестовый файл через `cat`/`grep` держит такие строки в литералах. |
| `sessionend.d/10-note-stub.cjs` (`note-stub-end`) | canary | Сессия поработала (правка или ≥ 10 вызовов инструментов) и закрылась без `/hub:wind-down` — заглушка `memory/sessions/<дата>-<ветка>-stub-<sid8>.md` (на основной ветке и в папке проекта — `session`). Wind-down сделан = заметка ветки (не заглушка) изменена после старта сессии. |
| `sessionstart.d/30-note-stub.cjs` (`note-stub-start`) | canary | SessionEnd не дошёл: на `startup`/`clear` новая сессия пишет заглушку для прошлой сессии той же папки (самый новый другой транскрипт рядом, тише 2 мин) и получает напоминание. |

## `last-full.json`

`node plugin/skills/checks/scripts/checks.cjs --full` пишет в git-папку worktree (`git rev-parse --git-path
hub/last-full.json`: у каждого worktree своя, уходит вместе с ним, в дереве не лежит) — `{sha, at, code, clean, base,
steps: [{name, status}]}`. Красный прогон тоже пишется: хук называет упавшие шаги. `clean` — дерево до прогона;
прогон незакоммиченного — не прогон HEAD. Проект без `checks.json` (сам хаб) — `done-facts` проверяет только отставание.

## Заглушка заметки

P7 (срез 04): SessionEnd приходит на `/exit`, Ctrl+C, обрыв терминала и архивирование в Desktop, на обработчик —
≈ 1,5 с; разбор транскрипта 47 МБ — ≈ 0,2 с (разбираются только строки со стартом и вызовами инструментов). Раздел
«Дальше» заглушки — то, что покажет бриф следующей сессии ветки (`latestNote`): подвести итог по транскрипту, заглушку
удалить. Повторный SessionEnd той же сессии второй заглушки не пишет.

## Откат

Стадия `off` в записи модуля (сразу) или revert + sync. `done-gate` в стадии `on` заменяет v1 (`stop.cjs` — только
вход v1 для сессий до хребта).
